5 الوضع الليلي والنهاري (Dark/Light Mode) 🌙☀️

✅ موجود في المشروع: الزائر يبدّل بين الوضعين، واختياره بيتحفظ في localStorage.

🎯 إزاي بيشتغل؟

  • بنستخدم CSS Variables — كل الألوان معرّفة في :root.
  • بنضيف كلاس .dark على عنصر <html> للتبديل.
  • الاختيار بيتحفظ في localStorage.
  • لو مفيش اختيار محفوظ، بنتبع إعدادات جهاز الزائر.

💻 كود مختصر

// hooks/useTheme.js
import { useEffect, useState } from 'react';

export const useTheme = () => {
  const [theme, setTheme] = useState(() => {
    const saved = localStorage.getItem('theme');
    if (saved) return saved;
    return window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark' : 'light';
  });

  useEffect(() => {
    document.documentElement.classList.toggle('dark', theme === 'dark');
    localStorage.setItem('theme', theme);
  }, [theme]);

  return { theme, toggle: () => setTheme(t => t === 'dark' ? 'light' : 'dark') };
};

7 المميزات التفصيلية

🕌 1) نظام الأذكار (Athkar Ticker)

  • يظهر فوق الصفحة في شريط ثابت.
  • كل 30 ثانية يظهر ذكر لمدة 5 ثواني ثم يختفي.
  • التنقل دائري بالترتيب.
  • لو الشخص مش شيخ (كاتب/مدرب) وسيبت athkar: [] → الشريط يتخفي تماماً.

🟥 2) تذكير الصلاة (Prayer Reminder)

جلب مواعيد الصلاة (Aladhan API) → مراقبة الوقت كل دقيقة → بعد دخول الوقت بـ 30 دقيقة → إظهار التنبيه → زرار "أه صليت"

ملاحظة: لو الشخص مش شيخ، ممكن نخليها اختيارية من settings.prayerReminder: true/false.

👁️ 3) عداد زوار الشخص

الحلالمميزاتالعيوب
مؤقت: localStorageسهل، بدون Backendمش عداد حقيقي

📢 4) الإعلانات (AdSlot) — رؤية كاملة

⏳ حالياً: المكوّن موجود لكن معطّل — بيعرض صندوق فاضي مخفي. لما الباك يخلص، بيتفعّل تلقائي.

السلوك المطلوب بعد ربط الـ API:

الزائر يدخل الموقع → بعد 3 ثواني → جلب الإعلان من API → إظهار Overlay بخلفية Blur → صور + عنوان + زرين

تفاصيل البوكس:

  • خلفية الموقع كلها بتبقى Blur (ضباب).
  • في وسط الشاشة بوكس الإعلان: صورة + عنوان فقط.
  • زرين فقط:
    • زر كنسل → يقفل الإعلان ويرجع الموقع طبيعي.
    • زر ادخل → يفتح رابط الإعلان في تاب جديد.
  • لو الزائر ضغط في أي مكان تاني على الشاشة (خارج البوكس) → مفيش حاجة تحصل.
  • الإعلان بيتحفظ في sessionStorage عشان ميتكررش في نفس الجلسة.
مهم: الإعلان Public من الـ API (نفس الإعلان لكل الزوار) مش Local.

🎬 5) مشغل الفيديو — يدعم أي منصة

مهم: مش شرط يوتيوب بس — أي رابط فيديو من (يوتيوب، فيسبوك، تيك توك، إنستجرام) يشتغل.

فكرة الـ videoParser.js:

  • بتاخد الرابط المدخل وتتعرف على المنصة تلقائي (regex).
  • تستخرج الـ ID وتحوّله لرابط embed مناسب.
  • لو مش قادر تتعرف على المنصة → تفتح الرابط في iframe مباشر.
// utils/videoParser.js
export const parseVideoUrl = (url) => {
  const patterns = {
    youtube: /(?:youtu\.be\/|youtube\.com\/(?:watch\?v=|embed\/|shorts\/))([\w-]+)/,
    facebook: /facebook\.com\/.+\/videos\/(\d+)/,
    tiktok: /tiktok\.com\/@[^/]+\/video\/(\d+)/,
    instagram: /instagram\.com\/(?:p|reel)\/([\w-]+)/,
  };

  for (const [platform, regex] of Object.entries(patterns)) {
    const match = url.match(regex);
    if (match) return { platform, id: match[1] };
  }

  return { platform: 'other', id: null };
};

شكل صفحة الكاتوجري بعد الدخول على فيديو:

  • اسم الكاتوجري فوق بخط كبير وواضح.
  • تحته بوكس الفيديو (مشغل من أي مصدر) + عنوان الفيديو تحته في نفس البوكس.
  • تحت الفيديو، باقي فيديوهات الكاتوجري بترتيبها (صورة مصغرة + عنوان).
  • زرار السابق يظهر لو في فيديو قبل الحالي.
  • زرار التالي يظهر لو في فيديو بعد الحالي.
  • كل ده جوّه الموقع — مفيش مغادرة للصفحة.

🔗 6) اللوجو + صورة الشخص فوق

  • اللوجو صغير في الـ Navbar.
  • صورة الشخص كبيرة في الهيرو (مع g_face عشان التركيز على الوجه).
  • لو مفيش لوجو (logo: "") → الاسم يظهر بخط شيك أنيق كأنه لوجو.
  • بجانب الصورة: البايو + الاسم + أيقونات السوشيال ميديا.
  • الخلفية لون متدرج مش صورة (أخف وأسرع).

📭 7) Fallback لما مفيش كاتوجري

متى يظهر؟ لما categories تكون فاضية [].

اللي بيتعرض بدل شبكة الكاتوجري:

  • نبذة موسعة عن الشخص (bioLong).
  • كارت معلومات مختصر: التعليم + سنوات الخبرة + الشهادات + المكان.
  • كل الـ customFields بتظهر بشكل شيك.
  • رسالة أنيقة تحت: "تابع كل جديد، قريباً المزيد على الموقع".
  • أزرار السوشيال ميديا كبيرة وواضحة.

📊 10) SEO — الهدف: الأول على جوجل

الهدف: لما حد يبحث عن اسم الشيخ/المدرب على جوجل، موقعك يظهر أول واحد — حتى على دومين Vercel المجاني.

اللي هنعمله:

  • Meta tags كاملة: title, description, keywords, author.
  • Open Graph لمشاركة شكل حلو على السوشيال.
  • Twitter Card.
  • Sitemap.xml في public/.
  • robots.txt للسماح لجوجل بالدخول.
  • Schema.org markup (Person) — ده اللي بيخلي جوجل يفهم مين الشيخ.
  • ربط الموقع بـ Google Search Console.
  • إضافة رابط الموقع في السوشيال ميديا بتاعت الشيخ.
